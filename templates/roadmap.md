# Roadmap

Este arquivo e o indice operacional das specs do harness.

Regras:

- Toda spec criada deve ser registrada aqui como `em andamento`.
- Toda spec finalizada deve ser marcada como `concluido`.
- Uma spec so pode ser marcada como `concluido` quando seus packages obrigatorios tiverem evaluation com Score 1 ou quando a excecao estiver documentada.
- Atualize este arquivo junto com `spec.md`, `progress.md` e `evaluations/package-N.md`.

## Status

Use estes valores:

- `planejado`
- `em andamento`
- `bloqueado`
- `concluido`
- `cancelado`
